# Seattle Weather Classification

Многоклассовая классификация погоды (5 классов) по метеоданным за 2012–2015 гг.
EDA, сравнение 8 алгоритмов, работа с дисбалансом классов, анализ ошибок.

## Задача

По ежедневным метеонаблюдениям в Сиэтле определить тип погоды: `rain`, `sun`, `fog`, `drizzle`, `snow`.

**Данные:** 1461 запись · 4 признака (осадки, t_max, t_min, ветер) · 5 классов.

**Проблема:** сильный дисбаланс классов — rain и sun вместе 88%, snow — 1.8%. Обычная accuracy здесь обманчива.

##  Навыки

`Python` · `pandas` · `NumPy` · `scikit-learn` · `matplotlib` · `EDA` · `feature analysis` · `classification metrics` · `model comparison` · `overfitting detection`

##  Что сделано

1. **EDA:** распределения признаков, анализ дисбаланса классов, проверка пересечений между классами.
2. **Предобработка:** кодирование целевого признака, train/test split 67/33.
3. **Бенчмарк 8 моделей:** SVM (linear/poly/rbf), kNN, Decision Tree, Random Forest, Gradient Boosting, Gaussian NB.
4. **Диагностика переобучения:** сравнение train/test error, детекция разрыва > 20 п.п.
5. **Эксперимент с нормализацией** (`StandardScaler`) и **PCA** — оценка влияния на качество.
6. **Анализ ошибок** через confusion matrix — какие классы модель путает и почему.

## 📊 Результаты

**Лучшая модель: SVM (linear)** — accuracy **84.7%**, macro-F1 **0.52**.
Стабильна: train 85.5% / test 84.7% — без переобучения.

| Модель | Train err | Test err | Комментарий |
|---|---|---|---|
| **SVM (linear)**  | 14.5% | **15.3%** | Лучший баланс |
| Gaussian NB | 15.1% | 15.3% | Стабилен, простой baseline |
| Gradient Boosting | 8.3% | 16.6% | Небольшое переобучение |
| Random Forest | 0.2% | 16.8% | Заметное переобучение |
| Decision Tree | 0.2% | 26.1% | Сильное переобучение |

## Ключевые выводы

- **Accuracy ≠ качество при дисбалансе.** 84.7% accuracy скрывает, что редкие классы (`snow`, `drizzle`) предсказываются плохо: recall snow ≈ 0.3. Macro-F1 = 0.52 — честная картина.
- **Дерево решений переобучается** (разрыв train/test 25.9 п.п.) — классический пример переобучения. Random Forest частично лечит, но не полностью.
- **Нормализация не дала прироста** — признаки уже в сопоставимых масштабах. Вывод: не тащить `StandardScaler` «на всякий случай».
- **Главный источник ошибок** — пересечение признаков rain/drizzle и snow/rain: при малом количестве осадков и температуре около 0 модель не различает их.
- **PCA не улучшил качество** — данных мало (1461), снижение размерности теряет сигнал.

## Ограничения

- Маленькая выборка (1461 запись) — модели нестабильны на редких классах.
- Один train/test split — без кросс-валидации оценка может быть оптимистичной.
- Гиперпараметры взяты по умолчанию — есть запас для тюнинга.
