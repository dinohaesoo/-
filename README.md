# Классификация погоды в Сиэтле

Учебный проект по курсу «Системы искусственного интеллекта»: многоклассовая классификация типа погоды по метеорологическим признакам. Сравниваются 8 алгоритмов машинного обучения, анализируется переобучение и влияние нормализации признаков.

## Задача

По ежедневным метеорологическим наблюдениям (осадки, максимальная/минимальная температура, скорость ветра) определить тип погоды. Всего **5 классов**: `drizzle`, `rain`, `sun`, `snow`, `fog`.

## Данные

Файл `seattle-weather.csv` — погода в Сиэтле за 2012–2015 гг.

| Признак | Описание |
|---|---|
| `date` | Дата наблюдения |
| `precipitation` | Осадки, мм |
| `temp_max` | Максимальная температура, °C |
| `temp_min` | Минимальная температура, °C |
| `wind` | Скорость ветра, м/с |
| `weather` | **Целевой признак** — тип погоды |

**Всего:** 1461 запись, 4 признака + целевой.

### Распределение классов

| Класс | Кол-во | Доля |
|---|---|---|
| rain | 641 | 43.87% |
| sun | 640 | 43.81% |
| fog | 101 | 6.91% |
| drizzle | 53 | 3.63% |
| snow | 26 | 1.78% |

Выраженный дисбаланс классов: `rain` и `sun` покрывают ~88% данных, а `snow` — менее 2%.

## Подход

1. **Предобработка:** удаление колонки `date`, кодирование категориального целевого признака в числовые метки (0–4).
2. **Разбиение:** 67% / 33% (train / test), `random_state=42`.
3. **EDA:** гистограммы распределения признаков.
4. **Обучение и сравнение 8 классификаторов:**
   - SVM с линейным ядром
   - SVM с полиномиальным ядром
   - SVM с RBF-ядром
   - k-ближайших соседей (kNN)
   - Дерево решений
   - Случайный лес
   - Градиентный бустинг
   - Гауссов наивный Байес
5. **Оценка:** ошибка на train/test, детекция переобучения (разрыв > 20 п.п.).
6. **Эксперимент с нормализацией:** `StandardScaler` + повторная оценка всех моделей.
7. **PCA:** визуализация объяснённой дисперсии компонент.

## Результаты

### Без нормализации

| Классификатор | Ошибка train | Ошибка test |
|---|---|---|
| **SVM (linear)**  | 14.5% | **15.3%** |
| Наивный Байес | 15.1% | 15.3% |
| Градиентный бустинг | 8.3% | 16.6% |
| Случайный лес | 0.2% | 16.8% |
| SVM (RBF) | 22.3% | 21.9% |
| SVM (poly) | 23.7% | 22.2% |
| kNN | 19.3% | 22.2% |
| Дерево решений | 0.2% | 26.1%  переобучение |

**Лучший результат:** SVM с линейным ядром — **точность 84.7%** на тесте.

### После нормализации (`StandardScaler`)

Лучший результат — **Наивный Байес** — **точность 84.7%** (SVM linear ухудшился до 79.3%). Дерево решений по-прежнему переобучается (0.2% / 25.9%).

### Выводы

- Линейный SVM и наивный Байес показывают наиболее стабильные и высокие результаты.
- Дерево решений сильно переобучается — классический пример.
- Случайный лес и бустинг имеют высокую точность на train при заметном разрыве с test.
- Нормализация не дала прироста качества для данного набора признаков.
- Дисбаланс классов — вероятная причина низкого качества на редких классах (`snow`, `drizzle`).
